{%- comment -%} Descriptive alt text for one capture's image, shared by the capture page and the /photos/ grid so the two can never drift apart. Built from the front matter scripts/generate_capture_pages.py already writes, so each image gets its own sentence instead of the same template with the title swapped out. Alt text is one of the main things Google Images ranks on, and near-identical strings across the whole gallery give it nothing to tell one capture from another. Everything except title, tag and location is optional: the comets have no catalogue, and the Sun and Moon have neither distance nor a meaningful object type, so each clause is conditional. A capture combining both scopes carries them as "Dwarf 3 + Dwarf Mini", which becomes "with Dwarf 3 and Dwarf Mini smart telescopes" — the singular article would be wrong across a pair. scripts/generate_capture_pages.py splits the same way for the meta description, so the two sentences stay in step. Callers should strip the result before putting it in an attribute: {%- capture alt %}{% include capture-alt.html capture=page %}{% endcapture -%} {%- endcomment -%} {%- assign c = include.capture -%} {%- case c.tag -%} {%- when 'nebula' -%}{%- assign kind = 'a nebula' -%} {%- when 'galaxy' -%}{%- assign kind = 'a galaxy' -%} {%- when 'cluster' -%}{%- assign kind = 'a star cluster' -%} {%- else -%}{%- assign kind = '' -%} {%- endcase -%} {{- c.title -}} {%- if c.catalogue %} ({{ c.catalogue }}){% endif -%} {%- if kind != '' %}, {{ kind }}{% if c.distance %} {{ c.distance }} from Earth{% endif %} {%- elsif c.distance %}, {{ c.distance }} from Earth{% endif -%} , photographed from {{ c.location | default: 'Edinburgh' }} with {%- assign scope_names = c.scope | default: 'Dwarf 3' | split: ' + ' -%} {%- if scope_names.size > 1 %} {{ scope_names | join: ' and ' }} smart telescopes {%- else %} a {{ scope_names[0] }} smart telescope{% endif -%}
