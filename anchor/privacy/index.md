**Anchor does not collect any data.**

There is no account, no sign-in, and no analytics. The app makes no network
connections of any kind — it contains no code to do so.

### What Anchor stores, and where

Anchor saves the positions of the icons on your desktop so it can put them
back. That data is file names, folder and volume names, and the coordinates
they sit at. For network volumes it also records the address the volume is
mounted from, so a drive that reconnects under a different name keeps its
position.

All of it is written to a single file on your own Mac, inside your user Library
folder. None of it is transmitted anywhere, and nobody else — including me —
can see it.

Your settings are stored alongside it, in the standard macOS preferences for
the app.

### Permissions Anchor asks for

**Automation access to Finder.** Desktop icon positions belong to Finder, and
there is no other supported way to read or change them. Anchor uses this only
to ask Finder where icons are and to tell it where to put them. It does not
read the contents of any file, and it does not move, copy, rename or delete
files.

**Notifications**, if you allow them, so Anchor can tell you when it has put
icons back, or ask what to do about icons you moved yourself.

Both are optional. Declining either leaves the app working as well as it can
without them, and it says so rather than failing silently.

### Removing your data

Deleting Anchor removes the app. To remove the saved layouts as well, delete
the `Anchor` folder inside `~/Library/Application Support`.
